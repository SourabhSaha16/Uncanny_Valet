Date: 2026-11-09

Tests: compile-checked outside Unity (all of Scripts and Tests compiled together against the Unity 6000.2.5f1 reference assemblies, no errors). The new pure fixtures (DilemmaRuleTests, DilemmaGateTests, DilemmaDirectorTests, ArchetypePickerTests, ArchetypeBoostTests, DirectorSoakTests, DirectorOverlayTextTests) were also run with a scratch NUnit-style runner: 50 passed, 0 failed, the 200-shift soak in about 0.7 s. Not run: fixtures that need the native Unity engine (DirectorBrainTests, DirectorProfileTests, TuningSeederTests, which create ScriptableObjects). New .meta files are not committed; Unity creates them on first import.
